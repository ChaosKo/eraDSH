## 修复

- **eraOCG / Emuera.NET EE+EM 启动卡住**：游戏进程不再继承工具的输出管道；`open` 只返回启动回执，不等待 IPC 或首屏。
- **加载中误判为可操作**：两套适配器明确返回 `phase / pending / canAct`；动作在 UI 线程校验当前真实输入请求，不再用历史画面授权。
- **动态刷新使合法输入持续过期**：分离展示版本和输入决策代次。对 eraMeiQ 已证实的 50 ms 动画输入循环，在执行位置、正文、选项和按钮代次均一致时延续同一菜单决策；提交后立即失效。
- **超时后迟到输入与回调异常**：统一等待预算，取消尚未执行的工作；已开始执行但超时的动作明确返回结果未知。
- 修复页外按钮选择，使用引擎权威按钮代次；Core 源码更新后，下一次构建会自动重新编译适配器。
- 更新 Era 预设，正常慢加载不会因为两次 `pending` 就被当成失败。

## 使用提示

- 更新后关闭旧游戏实例，重新 `build → open → observe`；等 `canAct=true` 再输入。旧进程不会自动替换已加载的适配器。
- `open` 成功只代表进程已创建；`pending=true` 时继续有界观测，不要重复 open。
- 结果未知时先观察，不要换新的 `actionId` 盲重送。
- 本 Release 提供源码归档，不包含游戏、存档、运行日志或预编译运行时。Core 引擎首次构建/适配器源码更新时需要 .NET SDK。
- 这是 GitHub Release，不是 npm 发布。
