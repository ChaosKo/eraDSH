## 新增

- **`render=compact`（工具默认）**：只改写可读投影，不动 `observationId`、按钮 id 与引擎行号。
  - 纯装饰行 → `▦(宽度)`；连续相同行 → `行 ×N`；长串同字符/空格 → `字符×N`；连续空行保留为空行并计数。
  - 布局标签保身份去几何：`<img src='FACE_4' height='200px' …>` → `⟨img FACE_4⟩`、`<div …>` → `⟨div⟩`，闭合标签丢弃；未知标签原样保留。
  - 按钮只留决策需要的字段（`id`/`label`/`integer`/短整数 `value`），label 内填充压缩；诊断字段（`displayHash`、`projectionId`、`window`、`buttonGeneration` 等）不下发。
  - `scripts/Invoke-Bridge.ps1` 仍是 `-Render full` 默认，显式 `-Render compact` 才压缩。
- **`act` / `advance` 自动回增量**：以调用方手上那一屏为基准（`advance` 取第一次回车之前），只回新增/改写行。新增内容覆盖窗口 60% 以上时自动回退整屏文本，`delta.reason` 说明原因。
- **EraFL 类启动噪音**：`正在构造用户定义函数列表`、`正在验证脚本语法`、`非注释行数` 等编译统计行并入噪声规则。

## 实测

| 屏幕（真实游戏） | compact / full | 比例 |
| --- | --- | --- |
| eraOCG2 决斗屏（84 行文本） | 2 770 / 6 262 字符 | 55.8% 节省 |
| eraFL 标题（累计缓冲） | 1 525 / 3 098 字节 | 49.2% |
| eraFL 状态页（CLEAR） | 4 522 / 8 126 字节 | 55.6% |
| eraFL 主菜单（CLEAR，24 按钮） | 3 103 / 6 790 字节 | 45.7% |
| eraFL `advance` 无变化 | 2 472 / 6 791 字节 | 36.4% |

反例已记录：当新增内容本身占满窗口时，逐行 JSON 的增量比整屏文本更贵（3 076 vs 2 109 字节），因此设了 60% 回退阈值。

## 使用提示

- 插件是 `link:` 安装时，脚本改动下次调用即生效；工具定义变化由 HMR 重载，无需重启 `dsh web`。
- 需要在同一次会话里看原文时传 `render: "full"`；`noise=raw` 仍然返回未过滤缓冲。
- `delta.kind=none` 表示这一屏没变，不必重读；`delta.kind=full` 才是整屏重发。
- 旧会话不会自动切换新的 Era 预设修订。
- 本 Release 提供源码归档，不包含游戏、存档、运行日志或预编译运行时。Core 引擎首次构建或适配器源码更新时需要 .NET SDK。
